SONG IMPORT FILES

Place song files you want to import in this folder. In Worship Studio, choose File > Import > Songs and select a file. Supported formats include OpenLyrics/OpenSong XML, Worship Studio JSON, and text; the import window lets you review songs before saving them.

Files placed here are not imported automatically. Imported songs are stored in the app workspace, separately from this folder. Back up your workspace as well as any original files.
