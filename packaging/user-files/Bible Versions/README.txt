BIBLE TRANSLATION IMPORT FILES

Place Bible translation files you have permission to use in this folder. In Worship Studio, choose View > Full mode, then File > Import > Bible translation. Select a supported file and review the import.

Supported formats include Zefania, OpenSong and OSIS XML, tab-separated references, and Worship Studio JSON. Files placed here are not imported automatically. Imported translations are stored in the app workspace. Back up your workspace as well as any original files.

This installer does not include Bible translations because the source database was not present in the project.
